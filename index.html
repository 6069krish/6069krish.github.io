🔑 Google OAuth setup — ~5 minutes

  • 1
    Go to console.cloud.google.com and create a new project (any name)
  • 2
    Go to APIs & Services → Library → search "Google Calendar API" → Enable it
  • 3
    Go to APIs & Services → OAuth consent screen → choose External → fill in App name → Save
  • 4
    Still on consent screen → scroll to Test users → add your Gmail address
  • 5
    Go to Credentials → + Create Credentials → OAuth Client ID → type: Web application
  • 6
    Under Authorized JavaScript origins add: https://yourusername.github.io
    For local testing also add: http://localhost:8080
  • 7
    Click Create → copy the Client ID → paste it in step 1 above
