🔑 Google OAuth setup (~5 min)
  • 1
    Go to console.cloud.google.com → create a project
  • 2
    APIs & Services → Library → enable Google Calendar API
  • 3
    OAuth consent screen → External → fill in App name → Save → Add yourself as test user
  • 4
    Credentials → Create → OAuth Client ID → Web application
  • 5
    Authorized JS origins: https://yourusername.github.io and http://localhost:8080
  • 6
    Copy Client ID → paste in Dashboard
